## Scoring key used throughout

- **Effort**: 1 = minutes, from home · 3 = hours, some in-person · 5 = sustained organizing over months
- **Impact**: 1 = symbolic · 3 = changes a member's vote or an institution's small holdings · 5 = directly changes weapons/money flow or who holds office
